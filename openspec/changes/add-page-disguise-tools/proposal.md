## Why

在办公环境中浏览知乎时，侧边栏、页签标题与图标、品牌配色、社交操作栏等特征很容易被旁人一眼识别；页面中的大图会进一步放大这种辨识度，也带来视觉干扰。需要在保留真实浏览行为的前提下，提供可开关的页面外观伪装与视觉降噪能力。

## What Changes

- 新增「知乎伪装」设置组，包含两个独立、全局持久、默认关闭的开关：
  - **文档视图**：在全部 `*.zhihu.com` 页面把知乎换皮为 POPO 风格浅色技术文档，正文保持可读。
  - **精简图片**：在全部站点隐藏渲染尺寸超过阈值的大图。
- 文档视图的具体表现：
  - 用与正文解耦的伪文档标题替换页签标题，按 URL 稳定映射，不把问题标题写进页签。
  - 用中性文档图标替换 favicon，并持续接管知乎 react-helmet 对 `<head>` 的重写。
  - POPO 浅色文档配色、伪页眉页脚、伪「系统架构」SVG 区块。
  - 隐藏知乎顶栏/Logo/搜索、左导航、右侧栏、右侧推荐模块、关注按钮、头像/徽章、作者操作栏（赞同/反对/评论/收藏/喜欢/分享/更多/收起）与版权页脚。
  - 保留问题标题、正文、评论内容、作者名（弱化为署名文本）与话题标签。
- 精简图片的具体表现：按渲染尺寸阈值判定，直接折叠；处理动态插入与懒加载图片。
- 两个开关都放在 popup 新增的「知乎伪装」分组，分组标题明确点明知乎，两行标签仍为「文档视图」「精简图片」，详细含义放在悬停提示与读屏标签中。
- 同步更新 popup 的 DOM 契约说明、AGENTS.md 的 popup 分组约定与 README 的功能说明。

**非目标（本次不做）**：

- 不伪装地址栏、链接悬停状态栏、右键菜单或 DevTools 网络面板中的 `zhihu.com`。
- 不改变知乎正文文字本身，问答内容仍可能自证来源。
- 不处理 CSS 背景图、iframe 内图片与 `<video>` 封面。
- 不提供主题切换、阈值调节、快捷键或临时「老板键」。

## Capabilities

### New Capabilities

- `zhihu-camouflage`: 在 `*.zhihu.com` 页面提供可开关的文档视图，隐藏知乎品牌与社交特征并替换页签标题、favicon 与整体配色，正文保持可读。
- `large-image-hiding`: 提供可开关的知乎页面大图隐藏能力，按渲染尺寸识别并折叠大图，处理动态插入与懒加载内容。

### Modified Capabilities

（无）

## Impact

- `manifest.json`：为知乎新增按键名匹配的 content script CSS（文档视图样式）与另一条只含大图隐藏规则的 content script CSS；把文档图标加入 `web_accessible_resources`。
- `zhihu-camouflage.js` / `zhihu-camouflage.css`：文档视图的标题与 favicon 接管、伪外壳注入、品牌与社交元素隐藏、POPO 浅色文档样式。
- `image-hiding.js` / `image-hiding.css`：大图判定、动态扫描与恢复。
- `src/assets/doc-icon.svg`：中性文档图标，用于替换 favicon。
- `popup.html` / `popup.js`：新增「知乎伪装」分组、两个开关与对应的读屏状态节点。
- 新增文件：文档视图样式、大图隐藏样式、中性文档图标。
- `AGENTS.md` / `README.md`：更新 popup 分组契约、存储键说明与功能列表。
- 不新增权限，不改 `background.js` 的网络通道，不进入 MAIN world。
- 两个开关互相独立，可与现有控制台开关、京东评价、AI 评语同时使用。
